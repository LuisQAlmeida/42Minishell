# Subject Provenance

This directory records the requirements provenance for the original 42
Minishell project.

The project was developed using the **Minishell version 10.0** subject from the
42 Common Core.

The original subject PDF was tracked during the academic project, but it is not
redistributed in the maintained public repository.

Its historical presence remains recoverable through Git history and the
immutable pre-modernization baseline:

`portfolio-baseline-2026-08`

Maintained academic metadata and evaluation context are documented in
[`../../academic/README.md`](../../academic/README.md).
