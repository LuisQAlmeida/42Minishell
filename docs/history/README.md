# Project History

This directory preserves documentation from earlier stages of the project.

The material is retained for provenance, traceability and engineering context,
but should not automatically be interpreted as documentation of the current
implementation or workflow.

## Contents

### `original-requirements/`

Original project requirements and supporting material from the 42 Porto
curriculum.

### `design/`

Architecture notes, design proposals and implementation-flow documentation
created during development.

Some of this material may describe intermediate designs that differ from the
final implementation.

### `planning/`

Implementation plans and development planning artifacts.

### `validation/`

Manual test matrices, evaluation preparation and validation evidence produced
during the original project.

### `team-workflow/`

Documentation describing the original collaborative development process,
including Jira conventions, Git workflow, working agreements and definitions
of readiness and completion.

## Documentation Lifecycle

The repository distinguishes between:

```text
current documentation
        |
        |-- architecture/
        |-- decisions/
        |-- development/
        `-- testing/

historical documentation
        |
        `-- history/
```

Historical documents are preserved instead of silently rewritten into current
documentation.

When historical material remains technically relevant, it may be reviewed and
used as evidence for new maintained documentation without erasing its original
context.
